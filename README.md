# 城邦演武

据点争夺类即时战略：摧毁敌城、进驻废墟、重建为己所用。地图、数值、规则与代码为原创。这个项目同时是一块试验田 —— 用一个足够大的 Canvas 2D 游戏去探 Tauri（WebView2）做图形应用的边界，并和 Electron、浏览器做对比。结论见 [对比实验报告.md](对比实验报告.md)。

美术素材均为 CC0：

- 角色：[0x72 DungeonTileset II](https://0x72.itch.io/dungeontileset-ii)（`game/assets/dungeon2/`）。马 / 鹿 / 狼 / 梦魇坐骑、投石车和攻击动作是代码画的，见 `js/sprites2.js`。
- 建筑与树木：[Kenney Tiny Town](https://kenney.nl/assets/tiny-town)（`game/assets/tinytown/`），据点按等级用 16px 图块拼装。
- 地面、水、岩石、粒子、光照、天气和法术特效全部是代码绘制。

同一份 `game/` 页面可以用三种方式跑：浏览器直接打开 `game/index.html`、`npm run tauri:dev`（Tauri 2 / WebView2）、`npm run electron:start`（Electron）。

## 两种玩法

**战役**：五个势力各 6 关，40×25 格的单屏地图，按用时评级换敕令点做局外成长。打通前一个战役的第 2 关解锁下一个。

**大陆征服**：程序生成的大地图（64×40 到 200×125 格），最多 8 方混战，带战争迷雾。噪声生成海岸、湖、山脊和树林，据点用最远点采样分给各家当都城，其余是独立城邦（会防守、不扩张）和废墟。可选规模、对手数量、地貌（温带 / 秋日 / 雪原 / 荒漠）、难度和种子，开局前能看到真实生成出来的地图预览。

## 操作

- **视角**：滚轮缩放（以鼠标位置为中心），按住右键或中键拖动地图，方向键平移，点小地图跳转，`Home` 回都城。拉远时士兵先去掉影子，再变成归属色的小点；旗标会自动放大，全图视角下也能拖旗下令。
- **出兵**：点己方城，再点下方兵种图标。练好的部队站在城的两侧。
- **拖旗下令**：按住部队头顶的圆形旗标（或部队本身）拖到目标松开：敌城 = 进攻，废墟 = 占领重建，己方城 = 进驻，空地 = 移动。城头那排小旗标是守军，同样能拖出来。
- **建造**：点城旁的木牌，金矿 / 方尖碑 / 农场 / 箭楼。
- **科技**：右上角「科技」或 `K`，五项各三级，花金币立刻生效。
- 也可以单击旗标选中再点目的地、空地拖框多选、右键取消。快捷键 `QWERTY` 出兵、`U` 升级、`1 2 3` 法术、空格暂停、`F` 加速、`F3` 性能面板。

## 规则摘要

- 势力：西境公国（回血、砸墙）、赤血部落（加速、火雨）、冰谷教团（减速、冻结）、金叶林盟（射程、机动、缠绕）、枯骨王庭（便宜耐打、瘟疫、召唤骸骨）。每家三个法术，第三个需要控制法塔。
- 兵种：步兵克骑兵，骑兵克弓手，弓手克步兵；投石车砸城墙 ×3.2；法师无视护甲；骑兵冲锋第一击 ×2.6；禁卫是三人一队的重甲溅射兵，需要 1 级以上的城堡。
- 据点：城镇、法塔、城堡、村庄（便宜、弱）、要塞（没什么收入但火力强）。每种可以升两级，升级后训练出的是老兵和精锐。每座据点旁有 3 个附属建筑位。
- 占领：先把城的耐久打到 0 变成废墟，再派部队进废墟重建。进驻的部队会回血，敌人靠近时自动出城迎战。
- 部队上限由据点和农场提供；科技：锻造、甲胄、驿道、城防、税制。

## 代码结构（`game/js`）

| 文件 | 内容 | 依赖 DOM |
|---|---|---|
| data.js / missions.js | 规则数值、势力、兵种、法术、科技、敕令、地貌、战役 | 否 |
| map.js | 可变尺寸地图、噪声地形与大陆生成、连通性修复、8 向 A*（二叉堆 + 路径拉直） | 否 |
| sim.js | 固定步长 1/30 秒，逐士兵模拟；空间哈希（48px 格）；确定性随机数；任意数量的归属方 | 否 |
| ai.js | 防守、经营、科技、按克制出兵、波次进攻、施法；也能托管玩家一方 | 否 |
| sprites2.js | 角色图集：势力 × 兵种 × 动画 × 朝向预合成，全部排进一张 2016×1300 的画布（同一张纹理，方便合批） | 是 |
| render.js | 相机；512px 分块烘焙地形，三级分辨率，按像素预算做 LRU 淘汰；视锥裁剪；按 y 排序；士兵三级 LOD；粒子、昼夜光照、云影、天气、战争迷雾、小地图。`CS.RF` 是渲染开关，用于消融测试 | 是 |
| ui.js / main.js | 界面、输入、DOM 差量更新、主循环、压力测试与结果上报 | 是 |

`sprites.js` 和 `assets/medieval/` 是早期版本留下的，现在不再加载。`backup_v1`–`backup_v3` 是历次改造前的快照，`backup_v3` 同时是对比实验的基线。

## 测试工具（`tools/`，Node 直接跑，无需浏览器）

```
node tools/headless.js duchy all 900        # AI 托管玩家，把一个战役跑一遍
node tools/headless.js conquest xl 3 600    # AI 全托管的大陆征服（规格 种子 最长秒数）
node tools/balance.js duchy 1,2,3           # 多个随机种子的胜负与用时
node tools/stuck.js                         # 检测部队卡在地形里
node tools/simbench.js 20000 l              # 大地图约 20000 士兵时的纯模拟耗时（士兵数 地图规格）
node tools/trace.js horde 3 1               # 打印某关据点易手时间线和双方兵力
```

## 压力测试与跨外壳对比

标题页「压力测试」可以选士兵数、地图规格、相机脚本和时长；也可以用地址参数直接进：`?bench=6000&map=l&secs=30&cam=tour`（`rf=light:0,particles:0` 这样的参数可以关掉某些画面特性）。测试时所有归属都由 AI 托管，据点打不坏，兵死了会补，负载稳定；补兵按模拟步数走，各个外壳里跑出来的战局完全一致。报告内容：平均 FPS、1% Low、帧时间分位数、卡顿帧数、模拟与渲染耗时、分阶段帧率、每 5 秒一个点的时间线、地形块烘焙数、JS 堆。

自动化对比（Windows）：

```
npx tauri build --no-bundle            # 先把页面嵌进 Tauri 的 release 可执行文件
npm --prefix electron run pack         # Electron 打包成目录
node tools/experiment.js all           # 启动、规模阶梯、改造前后、巨型地图、消融、浸泡，约一小时
node tools/experiment.js repeat        # 3000 / 6000 / 10000 兵各重复三次（均值 ± 标准差），约 40 分钟
node tools/experiment.js limit         # 15000 / 20000 / 30000 兵，加到跑不动为止
node tools/experiment.js limit --only=tauri --n=22500,25000 --reps=3   # 自选档位、外壳和重复次数
node tools/report.js                   # 汇总成 对比实验报告.md
```

报告里除了帧率，还有“模拟速度”（实际模拟步数 ÷ 实时应跑步数，低于 100% 说明游戏本身在变慢）和“主线程 JS 占帧时间”（越接近 100%，帧率越是被页面自己的 JS 卡住）。

`experiment.js` 逐个启动三个外壳，页面把结果 POST 回脚本起的本地服务，脚本同时每 2 秒采样一次整棵进程树的内存和 CPU 时间。外壳通过环境变量接收参数：`CS_QUERY`（传给页面的参数串）、`CS_URL`（改为加载外部地址，跑基线时用）。测试期间会不断弹出窗口，别挡住它们，也别同时跑别的重活。
