# 城邦演武 · 改造前基线（v2.5 快照）

这是 v3 改造之前的版本，留作对比实验的基线，不再维护。当前版本的说明见仓库根目录的 README。

据点争夺类即时战略。地图、数值、音效和音乐是原创或程序生成的。美术素材（均为 CC0）：

- 角色：[0x72 DungeonTileset II](https://0x72.itch.io/dungeontileset-ii)（`game/assets/dungeon2/`）。公国＝骑士 / 精灵 / 法师 / 矮人，部落＝兽人 / 哥布林，教团＝蜥蜴人 / 骷髅 / 死灵法师 / 恶魔。马、狼、投石车和攻击动作（挥武器）是代码画的，见 `js/sprites2.js`。
- 建筑与地形：[Kenney Tiny Town](https://kenney.nl/assets/tiny-town)（`game/assets/tinytown/`），城镇 / 法塔 / 城堡按等级用 16px 图块拼装，见 `render.js` 的 `drawStruct`。水面、岩石、法术特效为代码绘制。
- `game/assets/medieval/`（Kenney RTS Medieval）仍随包加载，目前只剩旧版本兼容用。

同一份 `game/` 页面可以用三种方式跑：浏览器直接打开 `game/index.html`、`npm run tauri:dev`（Tauri 2 / WebView2）、`npm run electron:start`（Electron）。

## 玩法

只用鼠标左键：

- **出兵**：点己方城，再点下方兵种图标。练好的部队站在城的两侧。
- **拖旗下令**：每队己方部队头顶有一面圆形旗标（兵种小像 + 人数 + 一圈血量）。按住旗标（或部队本身）拖到目标松开：敌城 = 进攻，废墟 = 占领重建，己方城 = 进驻，空地 = 移动。拖动时虚线指向目标，并写明将要做什么。
- **守军**：城头那排小旗标就是城里的守军，同样拖出来就能派走。
- **建造**：点城旁的木牌，在木牌上方弹出金矿 / 方尖碑 / 农场。
- 也可以单击旗标选中再点目的地，或在空地拖框多选后拖其中一队的旗标整组走。右键取消。快捷键（QWERT 出兵、U 升级、空格暂停、F 加速）保留为可选。

地图是 40×25 格、每格 20px（800×500），所以城和小人在屏幕上比以前大约 1.6 倍。以前按 32px 格子写的“地图距离”（AI 的各种半径）用 `CS.MAPK` 换算。

- 三个势力各有一个战役，每个 6 关：西境公国、赤血部落、冰谷教团。打通前一个战役的第 2 关，解锁下一个战役。
- 部队上限：城镇 3、法塔 2、城堡 4，农场 +2。
- 每队人数：步兵 6、弓手 5、骑兵 4、法师 3、投石车 2（单兵属性按人数折算，整队强度不变）。
- 法术：每秒基础法力 0.8（有据点就有），法塔和方尖碑另加。三个势力各三个法术，冷却 9–12 秒的小法术随时能用，第三个大招需要控制法塔。
- 据点分三种：城镇（步兵、弓手）、法塔（步兵、法师，并解锁第三个法术）、城堡（步兵、弓手、骑兵、投石车）。每种据点可以升两级，升级后训练出的是老兵和精锐。
- 每座据点旁有 3 个附属建筑位：金矿（金币）、方尖碑（法力）、农场（部队上限）。
- 占领流程：先把城的耐久打到 0，城变成废墟；再派部队进废墟重建，修好就归你。进驻的部队会回血，敌人靠近时自动出城迎战。
- 克制关系：步兵克骑兵，骑兵克弓手，弓手克步兵。投石车砸城墙伤害 ×3.2，法师无视护甲，骑兵冲锋第一击 ×2.6。
- 关卡按用时评级（完美 / 优秀 / 完成），评级换敕令点，用来做局外成长。

## 代码结构（`game/js`）

| 文件 | 内容 | 依赖 DOM |
|---|---|---|
| data.js / missions.js | 规则数值、势力、兵种、法术、敕令、9 张地图布局、3×6 关战役 | 否 |
| map.js | 地形生成、连通性修复、8 向 A*（二叉堆 + 路径拉直） | 否 |
| sim.js | 固定步长 1/30 秒，逐士兵模拟；空间哈希（48px 格）；确定性随机数 | 否 |
| ai.js | 防守、经营、按克制出兵、波次进攻、施法；也能托管玩家一方 | 否 |
| sprites2.js | 角色图集：0x72 角色 + 武器 + 代码画的坐骑 / 投石车，按势力 × 兵种 × 动画（跑 4、待机 4、攻击 2、受击、倒地）× 朝向预合成 | 是 |
| sprites.js | 旧版程序化小人（已不用）和 Kenney RTS 图块索引 | 是 |
| render.js | Canvas 2D：烘焙地形 + 按 y 排序（对象池）+ 特效；`CS.RF` 渲染开关，用于消融测试 | 是 |
| ui.js / main.js | 界面、输入、DOM 差量更新（按钮元素保持稳定）、主循环、压力测试 | 是 |

## 测试工具（`tools/`，Node 直接跑，无需浏览器）

```
node tools/headless.js duchy all 900   # AI 托管玩家，把一个战役跑一遍
node tools/balance.js duchy 1,2,3      # 多个随机种子的胜负与用时
node tools/stuck.js                    # 检测部队卡在地形里
node tools/simbench.js 2000            # 约 2000 士兵时的纯模拟耗时
node tools/trace.js horde 3 1          # 打印某关据点易手时间线和双方兵力，查平衡用
```

## 跨外壳性能对比

在游戏标题页选「压力测试」（或在 URL 后加 `?bench=1000`）。测试会先往地图上投放兵力，再测量 30 秒，报告平均 FPS、1% Low、P95/P99 帧时间、模拟耗时和渲染耗时，并自动识别运行环境是 Browser、Tauri 还是 Electron。

同一档兵量在三个环境里各跑一次，就是一组可直接对比的数据。结果同时写在 `window.__bench` 和 `document.body.dataset.bench` 里，方便自动化读取。

无头 Chrome（软件光栅，1358×849）的参考数据：

| 士兵数 | 平均 FPS | 渲染 / 帧 | 模拟 / 帧 |
|---|---|---|---|
| 约 1550 | 55 | 5.6 ms | 0.8 ms |
| 约 2200 | 32–36 | 8–20 ms | 1.5–3.6 ms |

Node 纯模拟：2000 士兵约 1.0–1.25 ms/步。
